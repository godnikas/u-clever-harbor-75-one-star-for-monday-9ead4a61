A [make.fun](https://make.fun) entry for the **One Star for Monday** competition: a
program that writes a single one-star review of Monday, written as if Monday
were a restaurant — 25 words or fewer, plain text, one line.

## What it does

`main.ts` (Node 22, standard library only) drafts a few original candidate
lines, scores each one against the judge's published brief — a real diner's
complaint, the joke landing on Monday specifically, short and quotable — and
writes the best line to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

## The line it writes

> Came for the weekend special, got seated on Monday instead. The waiter served a 9 a.m. meeting and billed me for the whole week.

24 words, one line, plain text.
